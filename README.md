# RasanyaChips — Paket Dokumen SOT

Paket ini berisi dokumen spesifikasi dan kontrak awal untuk proyek Sistem Informasi Berbasis Website Menggunakan React Vite dengan Metode RAD pada Toko RasanyaChips.

## Isi paket
- `docs/sot/PRD.md` — kebutuhan produk dan tujuh modul.
- `docs/sot/UI-GUIDELINE.md` — identitas visual dan aturan antarmuka.
- `docs/sot/IMPLEMENTATION_PLAN.md` — arsitektur dan rencana pengerjaan.
- `AGENTS.md` — kontrak kerja coding agent.
- `PROMPT_EXECUTION.md` — prompt eksekusi awal.
- `README.md` — panduan paket.

## Status
Ketiga dokumen SOT telah disetujui sebagai dokumen perencanaan. Paket ini tidak berisi implementasi aplikasi React, backend, atau database.

## Cara menggunakan
1. Ekstrak ZIP ke folder kerja proyek.
2. Tinjau dokumen di `docs/sot/`.
3. Baca `AGENTS.md`.
4. Gunakan prompt pada `PROMPT_EXECUTION.md` saat memulai coding agent.
5. Tentukan backend/database dan kebutuhan produksi sebelum integrasi nyata.

## Keputusan penyimpanan data
Belum diputuskan. Rekomendasi harus mempertimbangkan apakah aplikasi digunakan hanya pada satu perangkat atau oleh beberapa admin, kebutuhan autentikasi, biaya operasional, dan kemampuan pemeliharaan.
